## Riesgos y ensayos a planificar

| **Elemento**              | **Riesgo**                                    | **Ensayo propuesto**                                                                |
| ------------------------- | --------------------------------------------- | ----------------------------------------------------------------------------------- |
| Dosificación de quitosano | Dosificación inexacta de la mezcla            | Realizar varias dosificaciones y comparar el volumen entregado.                     |
| Sensor de turbidez        | Lecturas variables o incorrectas              | Comparar lecturas antes y después de la clarificación bajo condiciones controladas. |
| Sensor de pH              | Lecturas inestables                           | Realizar mediciones repetidas y verificar estabilidad de la señal.                  |
| Sensor de nivel            | Detección incorrecta del nivel de agua        | Probar diferentes niveles de llenado y verificar la activación del sensor.          |
| Actuador del agitador     | Posicionamiento inadecuado del agitador       | Evaluar diferentes posiciones y verificar el correcto desplazamiento del actuador.  |
| Control del agitador      | Tiempo de agitación inadecuado                | Evaluar diferentes tiempos de agitación mediante el relé y temporizador.            |
| Comunicación Bluetooth    | Pérdida de transmisión de datos               | Verificar la transmisión de las mediciones durante el funcionamiento del prototipo. |
| Alimentación              | Insuficiencia de energía para los componentes | Medir el consumo del sistema durante una operación completa.                        |
| Carcasa                   | Ingreso de agua o dificultad de manipulación  | Evaluar el aislamiento y la facilidad de acceso a los componentes.                  |
