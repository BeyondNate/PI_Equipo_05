## Simulación en SimScale

Se realizó una **prueba de presión vertical hacia abajo (compresión)** sobre el soporte universal. Para la simulación se asignó **acero (steel)** como material y se aplicó una fuerza de **-5 N**, con el objetivo de analizar cómo responde el soporte ante la carga aplicada y observar las posibles deformaciones que pueda presentar.
