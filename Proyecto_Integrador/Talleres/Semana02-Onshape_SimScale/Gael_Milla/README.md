## Simulación en SimScale

Se realizó una **prueba de fuerza vertical hacia abajo (compresión)** sobre el soporte triangular. Se aplicó una fuerza de **-10 N**, con el objetivo de analizar cómo responde el soporte ante la carga aplicada y comprobar su resistencia.
