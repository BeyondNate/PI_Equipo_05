## 📌 Descripción de la actividad

En esta actividad se desarrolla un modelo de **Red Neuronal Convolucional (CNN)** para la clasificación de caracteres del conjunto de datos **EMNIST ByClass**, diferenciando entre **letras y números**. Para ello, se trabaja con una muestra de **15,000 imágenes**, distribuidas en conjuntos de entrenamiento, validación y prueba.

Además, se compara el desempeño de una CNN desarrollada desde cero con una CNN utilizando **Data Augmentation** y un modelo de **Transfer Learning mediante ResNet18**. Finalmente, se evalúan los modelos mediante diferentes métricas y se utiliza **Grad-CAM** para visualizar las regiones de las imágenes que influyen en las predicciones.
