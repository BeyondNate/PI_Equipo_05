# ACTIVIDAD LEONEL URBANO

Se realizó un esquemático compuesto por los módulos de **procesamiento (ESP32) y sensor de pH**. El ESP32 se comunica con el sensor de pH para recibir las mediciones, utilizando además resistencias de 1 kΩ y 2 kΩ para conectar correctamente el circuito.
